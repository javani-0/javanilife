# SEO audit: www.javanilife.com (Javani Spiritual Hub), 2026-11-06

Step 1 (read-only audit). No code changed yet.

## What the site is

- Classical dance and music academy in Secunderabad (Bharatanatyam, Kuchipudi, Carnatic music, yoga, konnakol), plus a shop (costumes, instruments, books, rentals) and monthly fee classes.
- Stack: React 18 + Vite SPA (react-router), Firebase/Firestore (client-side reads), Vercel (project `javani-sprirtual`, 12 serverless functions in `api/`).
- Domains: `www.javanilife.com` (canonical host). `javanilife.com` → 307 → www. `http://` → 308 → https. `javanailife.store` is set in `vercel.json` to redirect to `/products`, but it **does not resolve in DNS** today.
- SEO today: one `src/components/SEO.tsx` that sets title/meta/canonical/JSON-LD **in the browser after JS runs**. Nothing is in the initial HTML except the home-page defaults.

## Proposed order of fixes (steps 2-5, awaiting your OK)

1. Fix the canonical and JSON-LD domain (one constant).
2. robots.txt + noindex routes + `trailingSlash` 301.
3. `/sitemap.xml` + per-page HTML head for detail pages + build-time prerender of the static pages (all inside existing functions).
4. Titles, descriptions and OG per page; own OG image; trimmed detail descriptions.
5. JSON-LD (Organization, WebSite, LocalBusiness, Product, Course, BreadcrumbList) validated by script + Rich Results Test.
6. Performance: images (largest win, about 50 MB off the home page), fonts, bundle split, favicon.
7. Local/off-site list, then Search Console + Bing (javani Chrome), then live checks after your deploy yes.
